"what does Workload Factory say about this database?"

MSSQL Oracle Read · Trigger · Patch · Dismiss

1What this is

A skill is a small bundle (instructions + reference docs) you give to an AI agent so it can perform a specific task reliably. This skill teaches the agent to read NetApp Workload Factory registered (continuous) drift assessments for managed MSSQL and Oracle databases — and, with explicit user confirmation, trigger an on-demand re-assessment, run a patch scan, or dismiss a finding.

What the agent does automatically

  • Routes to the right engine by keyword (SQL Server / MSSQL / AOAG / FCI → MSSQL; Oracle / ASM / RAC / PDB → Oracle), by identifier hint, or by asking the user.
  • Walks the right read order: account scan → host drill-down → instance drill-down with scoped fields.
  • For triggers, polls the returned jobId until COMPLETED / FAILED, then re-fetches the instance and presents the new findings.
  • Recognises ErrorResponse shapes returned in place of a finding and surfaces them instead of pretending the dimension is healthy.
  • Defaults to staging when the environment is unstated; explicitly confirms before hitting production.

4What it intentionally does NOT do

These are deliberate scope choices. If a user asks for any of these, the agent refuses cleanly and points to the right channel.

✗ Offline / one-time WAD uploadOut of scope. Use the Workload Factory UI or the offline-assessment skill.
✗ Apply / remediate / "fix now" / optimizeThis skill is read- and assessment-only. It will not call *-optimize, optimize/storage-configuration, optimize/storage-layout, or database-hosts/optimize.
✗ Provision FSx / EC2 / databasesWorkload Factory provisioning flows are owned by other skills.
✗ Discover unregistered databasesOnly databases already managed/registered by Workload Factory are in scope.
✗ Trigger / dismiss without confirmationBoth flows require explicit user confirmation; the agent will not silently mutate state.

5How to install

A skill is just a folder with a SKILL.md inside it. Two steps:

  1. Copy the databases-wad/ folder into your agent's skills directory
    (e.g. ~/.cursor/skills/, ~/.claude/skills/, .opencode/skill/ — depends on the platform).
  2. Restart the agent (or have it re-scan its skills directory).

The agent reads SKILL.md's frontmatter description and decides automatically when to load the skill — no manual wiring needed. The two engine reference files in references/ are loaded on demand once the agent has picked an engine.

6What's in the box

databases-wad/

├── README.md                ← developer notes

    └── oracle.md              · Oracle endpoints, dimensions, response shapes, examples

Pure markdown. No pip install required. The skill talks to the Workload Factory wlmdb/v1 REST API directly via curl in agent-built requests.
